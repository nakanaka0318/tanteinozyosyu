## 遊び方

`index.html` をブラウザで開くだけで遊べます（インストール・ビルド不要）。
GitHub Pages で公開すれば、URL を共有するだけで誰でもプレイできます。

| 操作 | キーボード | タッチ |
| --- | --- | --- |
| 移動 | 矢印キー / WASD（Shift で早歩き） | 十字ボタン |
| 調べる・話す・決定 | Z / Enter / Space | A ボタン |
| 手帳を開く・戻る | X / Esc | B ボタン |

- **スマートフォン対応**：縦持ち・横持ちどちらでも遊べます。縦持ちでは縦長の画面、横持ちでは左右に操作ボタンを配置したレイアウトに自動で切り替わります。会話は画面タップでも送れます。
- 進行状況は自動でブラウザに保存されます（タイトルの「つづきから」）。
- 迷ったら、後ろをついてくる**九条に話しかける**とヒントがもらえます。

## 物語の構成

| 章 | 内容 |
| --- | --- |
| 序章 | 嵐の館へ到着。晩餐の席で、主人・源一郎が「十年前の罪」の告発を宣言する |
| 第一章「時計の止まる夜」 | 22時40分、書斎から響く物音。九条とともに現場を調べる |
| 第二章「証言」 | 館の人々から証言を集める。九条にはできない「助手の仕事」も |
| 最終章「時計は嘘をつかない」 | 九条の推理ショー。求めに応じて証拠を提示し、真犯人を追い詰める |
| 終章「夜明け」 | 事件の後で |

主役はあくまで探偵・九条です。プレイヤーは助手として現場を調べ、証言を引き出し、
推理の場面では九条の求める証拠を手帳から差し出します。
選択や提示の正確さによって「九条からの信頼」が変化し、エンディングの評価（S〜C）が決まります。

## 電脳展編のシステム

- **電脳ダイブ（ターン制バトル）**：助手が美術館のネットワーク「電脳層」に潜り、AI「MUSE」と組んで防御プログラムと戦います。
  アタック／スキル（デコード・シールド・リペア）／アイテム／**九条に相談**（敵の弱点と行動を見抜き、攻撃力アップ）。
- **論戦バトル**：最終局面では、犯人の反論に証拠をつきつけて「心の防壁」を崩します。証拠を間違えると「集中力」が減ります。
- **敗北パターン**：ダイブ中の戦闘に負ける／犯人の指名を誤る／集中力が0になる → GAME OVER。直前からやり直せます。

## 怪盗と宝玉編のシステム

- **代理探偵（時間制限つき捜査）**：九条の死後、プレイヤーが探偵として捜査します。調べる・話を聞く・エレベーターで移動するたびに時間が進み、**23:00**までに手がかりを揃えなければなりません。
  調べる前には所要時間が表示されるので、無駄足を踏まないように。迷ったら手帳の設定から「九条の言葉を思い出す」でヒントが聞けます。
- **告発**：九条の代わりに、自分の口で推理を組み立てます。証拠を間違えると「決意」が減り、0になると敗北。最後は犯人との論戦で心の防壁を崩します。
- **敗北パターン**：時間切れ／犯人の指名を誤る／決意が0になる → GAME OVER。直前からやり直せます。

## 名探偵シエスタ編のシステム

- **機内捜査**：探偵はシエスタ。ついてくるシエスタに話しかけるとヒントがもらえます（ただし、だいたいマイペース）。
- **推理と論戦**：シエスタの求めに応じて証拠を提示し、最後は犯人との論戦へ。間違えると「集中」が減ります。
- **機内戦（ターン制バトル）**：《シード》を飲み異形と化した犯人は、あらゆる音を聴き取る異常な聴覚を持ちます。
  普通に殴っても足音で読まれてしまう――アタッシュケースに隠された“切り札”で、聴覚をマヒさせて戦いましょう。
- **敗北パターン**：犯人の指名を誤る／集中が0になる／機内戦に負ける → GAME OVER。直前からやり直せます。

## 演出

- ドット絵のマップとキャラクター、ランプや暖炉の灯りによるリアルタイムの陰影表現
- 嵐の稲光、窓を伝う雨、柱時計の振り子などのアニメーション
- ノワール調の立ち絵（表情差分つき）、タイプライター式の会話演出
- 証拠品入手カード、証拠提示のカットイン、時系列タイムライン、セピア調の回想シーン
- BGM・雨音・効果音はすべて Web Audio API でその場で合成（外部音源なし）

## GitHub Pages での公開

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にし、ブランチ（`main` または `master`）と `/ (root)` を選んで保存
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります
